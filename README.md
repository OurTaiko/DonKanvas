# Web TJA Studio

基于 Vue 3 + Vite 的纯前端 TJA 波形与音符编辑器。谱面解析、编辑、历史与音频处理均在浏览器完成，无需后端接口，不上传文件。只有明确执行“保存”时才会写回关联的谱面文件，音频不会被修改。

## 启动

需要 Node.js 20.19+ 或 22.12+（当前使用 Node.js 24）。在本目录运行 `npm install`，然后运行 `npm run dev`（或 `npm start`）。浏览器打开终端打印的本机地址，默认 http://127.0.0.1:4173。端口占用时自动选择后续端口，开发时支持 Vue 热更新。

点击“新建”创建空白谱面，或通过“打开谱面”手动选择一份或多份 TJA。没有音频也可直接播放谱面音符音；通过“载入音频”手动选择伴奏，或点击“关联音频文件夹”，授权后自动匹配谱面 WAVE 字段指定的音频。

## 构建与结构

运行 `npm run build` 生成 `dist/`，再运行 `npm run preview` 验证构建。将 `dist/` 部署到任意 HTTP(S) 静态托管即可，也支持部署在子目录，无需 `/api/files` 或 `/media/` 接口。Node.js 仅供开发和构建使用；浏览器运行不需要 Node.js。不要直接双击构建后的 HTML，请使用静态文件服务。

- `App.vue`：应用外壳、文件操作、播放与混音控制。
- `TimelineEditor.vue`：Canvas 波形、时间网格、格子检查器与小节导航。
- `MeasureEditor.vue`：小节源码、任意落点指令与指令列表。
- `useStudio.js`：多谱面状态、兼容旧版本的本地草稿、Web Audio 调度与生命周期清理。
- `history.js`：可逆文本 diff，每份谱面最多保留 50 步编辑历史。
- `media-files.js`：在用户授权的目录内解析 WAVE 相对路径、匹配本地音频。
- `metadata.js`：歌曲元数据读取、验证与保留未编辑内容的修改。
- `chart.js` 等纯 JavaScript 模块：保留原有解析、分段时序、精确落点和音效逻辑，界面不再依赖全局解析器或手动 DOM 重建。
- `vite.config.js`：Vue 与静态构建配置，不提供本机文件读取接口，构建产物不包含本地谱面和音频。Windows 可双击 `start.cmd` 启动开发服务器。

## 谱面管理与历史

- 文件标签与下方编辑区属于同一面板，活动标签与编辑内容使用同一背景。标签可切换、关闭；修改当前文件名会解除旧文件关联，下次保存时选择新位置，不会直接重命名或覆盖旧文件。同名文件会作为不同谱面打开。
- 谱面标签超出宽度时，鼠标滚轮可左右滚动（兼容触控板横向滚动）；悬浮半透明滚动条仅在鼠标进入、键盘聚焦或拖动时显示，不占用标签布局。可拖动滑块、点击轨道，或聚焦滚动条后用左右键、PageUp/PageDown、Home/End 导航；无溢出时不影响页面正常滚动。
- 每份谱面独立保留编辑内容、当前难度、小节、音频、循环范围及撤销/重做历史。切换时暂停播放，待应用的源码会先尝试同步；错误源码保留在原标签，不影响其他谱面编辑。
- 每份谱面最多保留最近 50 步有效编辑，以可逆文本差异保存，不为每一步复制整份谱面。撤销后进行新编辑只清空当前谱面的重做分支；切换难度不会清空历史。界面显示当前撤销/重做步数。
- 有效编辑、未生效的源码及历史自动保存到当前浏览器的本地工作区。刷新时自动恢复所有谱面，也可点击历史按钮恢复；兼容原有单谱面草稿。音频仅在当前页面内存中保留，刷新或恢复后需重新载入。
- 星号表示存在未保存的修改或无效源码。关闭未保存的谱面会先确认；确认后会同时移除该谱面的本地草稿和历史。保存期间不能关闭对应谱面或恢复工作区。草稿不替代文件保存，本地存储不可用或空间不足时会提示，请及时保存文件。

## 保存与另存为

- 在支持 File System Access API 的 Chrome / Edge 中，通过“打开谱面”选择的文件会与当前标签关联。“保存”（Ctrl+S）写回关联文件；“另存为”（Ctrl+Shift+S）选择新的文件位置，成功后将当前标签关联到新文件，不另开标签。新建谱面首次保存也会选择位置。
- 文件系统接口需要安全上下文（HTTPS 或 localhost）及浏览器授权。文件句柄不会写入浏览器草稿；刷新或恢复后，首次保存需要重新选择位置。
- 保存统一使用带 BOM 的 UTF-8，包括原为 Shift-JIS 的谱面；直接保存会将原文件转换为此编码。另存为可保留原始文件。文件名不再自动附加 edited。
- 只有写入并关闭文件流成功后才标记为已保存。取消、权限拒绝或写入失败会保留修改；检测到磁盘文件已变化时会先确认是否覆盖。保存期间可继续编辑或切换标签，后续修改不会误标记为已保存。撤销/重做到最近保存的内容会相应更新星号。
- 不支持此接口的浏览器通过下载副本保存，不会写回原文件；“另存为”会先询问文件名，路径由浏览器下载设置决定。由于无法确认下载是否完成，会明确提示并保留未保存标记，请确认副本已下载后再关闭。
- 两个保存快捷键在源码和其他输入框聚焦时也生效，保存前会同步待应用的有效源码；无效源码会阻止保存，不会用旧内容覆盖文件。

## 音频与无伴奏播放

- 无需音频即可播放、暂停、定位、变速和试听小节或范围循环，普通音符及长音使用相同的合成音效。关闭范围循环后，在谱面最后一个时间分段结束时停止；关闭音符音或把咚咔音量调为零时仅运行播放头。载入伴奏后仍以音频时长为播放边界。
- 浏览器不能仅凭一个谱面文件的权限读取旁边的音频。点击“关联音频文件夹”明确授权一次，可先关联再打开谱面，也可打开后关联；打开、切换或恢复谱面时，自动为尚未载入音频的谱面匹配 WAVE。已有手动载入或缓存的音频不会被替换。
- Chrome / Edge 使用只读目录授权；其他支持目录选择的浏览器通过文件夹选择器建立本次页面内的文件索引。匹配过程完全在本地进行，不上传文件、不请求任意 WAVE 网址，也不会修改音频。
- 支持中文、空格、子目录、Windows 路径分隔符和授权目录内的 `..` 相对路径。原生打开的谱面在已授权目录内时，以其实际所在位置解析 WAVE；目录选择器则可通过唯一的谱面文件名定位。恢复的谱面没有原文件句柄时，请关联该谱面实际所在的文件夹。同名谱面或大小写匹配存在歧义时会提示，不猜测文件位置。
- 文件缺失、权限拒绝、路径超出授权目录或音频无法解码时明确提示，仍可无伴奏播放，也可改为手动载入。载入音频会暂停播放，完成后可重新播放。
- 文件夹关联和音频仅在当前页面内存中保留；刷新后需要重新授权文件夹或手动载入音频。无需逐张重新选择已授权文件夹内的音频。

## 紧凑工作区与歌曲信息

- 产品图标用于应用标识与浏览器标签页，产品名称统一为 Web TJA Studio。工作区无外围留白与卡片圆角，标签和编辑区横向贴齐浏览器边缘，仅在控件内部保留必要间距。顶部使用紧凑工具栏，默认不展开歌曲信息与音量面板，为谱面轨道留出空间。
- 点击“歌曲信息”打开弹窗，可编辑 TITLE、SUBTITLE、ARTIST、GENRE、WAVE、基础 BPM、OFFSET 和 DEMOSTART。点击“应用歌曲信息”后统一验证并作为一次可撤销编辑保存到谱面与草稿；取消或 Escape 不修改谱面。弹窗内 Ctrl+S / Ctrl+Shift+S 会先应用再保存 / 另存为。
- 元数据修改保留其他字段、注释、换行格式和各难度源码。清空可选字段会移除对应的全局定义。DEMOSTART 仅修改 TJA 的试听起点元数据，不会改变编辑器的播放位置。
- 更改 WAVE 会暂停播放、解除旧音频，并按已授权文件夹重新匹配；撤销或重做 WAVE 修改也会重新匹配。找不到音频时仍可无伴奏播放。
- 点击“音量”在同一区域调整音乐音量、咚咔音量和音符音开关，不再提供独立试音按钮。合成混音仍经过动态压缩以降低过载风险。

## 编辑

- 波形和音符轨道共用音乐时间轴。TJA 时间转换为音乐时间时减去 OFFSET。
- “歌曲信息”中的“基础 BPM”修改全曲头部 BPM，不覆盖已有 BPMCHANGE。右侧“落点指令”支持小节内任意可精确表达位置的 BPMCHANGE、MEASURE、SCROLL、GOGOSTART/GOGOEND 和正负 DELAY，支持撤销、草稿保存与导出。
- 点击音符轨道中的格子，指令位置会跟随其精确分数；也可直接输入“位置分子 / 分母”（0/1 为起点，1/1 为末端，分母最多 65536）。勾选该处需要的指令、设置数值后点击“应用落点指令”。未勾选的类型在该处不设置指令；取消勾选已有类型后应用会移除该类型，恢复前文继承。Go-Go 可选择开始或结束，延迟设为 0 会移除该处的 DELAY。
- “本小节指令”列出包含起点和小节内部的全部受支持参数指令、源码分数及音乐时间。点击指令定位并修改，垃圾桶删除单条；重置图标清除当前落点的参数指令，不影响其他位置。
- BPM、拍号、卷轴和 Go-Go 从所在落点持续生效，直到后续同类指令覆盖。小节内部按各分段的 BPM 与拍号计算实际时长；正 DELAY 在该落点等待，负 DELAY 将后续音符与小节提前，不改变音频本身，也不均摊到其他格子。同一位置多条 DELAY 按源码顺序累加。末端指令在逗号前执行，其状态传递到下一小节。延迟须为有限秒数，设为 0 会移除该落点的 DELAY。
- 负延迟可使时间分段或相邻小节重叠。视窗与循环覆盖所选小节所有分段，不以最后的时间游标截断提前前后的音符；点击已有音符优先选中音符本体，重叠区空白落点的反向定位优先使用源码靠后的分段。相同时间的音符可能重叠显示。音乐时间小于 0 的音符可编辑与导出，但播放从音频 0 秒开始，不会播放负时间音符。
- 试听、范围循环包含起始小节的节前延迟，时间轴标示所有延迟区间、指令位置与 Go-Go 区间。卷轴倍率允许 0 和负数，会随 TJA 导出；波形编辑视图保持音乐时间比例，不模拟游戏中音符的滚动、停顿或反向移动。
- 任意落点需要时会无损扩展源码格数，不移动旧音符或已有指令的位置；无法精确保留事件位置的细分转换会被拒绝，混合细分仍受单小节 65536 源码格上限约束。
- 点击小节导航选择小节。上方波形点击定位播放头，下方音符网格点击选中格子并暂停播放，不会直接修改谱面；右键也仅选中。
- 谱面轨道采用连续时间轴，可用鼠标滚轮、触控板或底部滚动条平滑左右浏览，不再按固定的小节组翻页。纵向滚轮映射为横向滚动，Ctrl / Command + 滚轮保留浏览器行为；系统启用减少动态效果时使用即时滚动。时间轴聚焦后支持左右键、PageUp/PageDown、Home/End。
- 滚动不会切换选中小节、移动播放位置或修改源码，各标签在当前页面中独立保留浏览位置。波形、音符、指令、长音及点击定位共用同一个连续视窗；负时间分段也可滚动查看。
- “缩放”只改变时间比例，参考基础 BPM 下的 4/4 小节时长，支持 1/16 至 8 小节宽，不限定可见的小节数量。密集吸附时可放大，画布始终只绘制当前视窗，不为整首谱面创建超宽位图。
- “格子信息”显示小节、格位、小节内精确分数、音乐时间、当前音符以及长音状态。选中后在面板里点击具名音符按钮才写入，选择“空拍”删除。尚未选择格子时音符按钮禁用。
- 选中格子后，数字键 0–9 可设置对应音符，左右键切换小节。编辑器中按空格播放 / 暂停，焦点在音符按钮或小节导航按钮上时也生效；长按不会反复切换。输入框、歌曲信息弹窗和音量展开按钮保留原生键盘操作，不截获空格。
- 右侧“小节源码（含指令）”同时包含音符和完整指令，可直接编辑，输入后 250ms 自动应用；须只包含一个以逗号结束的小节。无效输入不会修改有效谱面，修正前不能保存或切换小节。增删气球仍同步维护对应 BALLOON 次数。
- 每小节保持 16 格主网格，每 4 格加重一条网格线。“吸附细分”独立选择 4/8/12/16/24/32/48/64/96/192，或选“自定义”输入每小节 1–768 的任意整数等分（包括 5、7、9 等连音）。这里的数值指每小节等分数，非 4/4 拍时不等同于全音符分母。
- 选择细分后显示虚线辅助线，鼠标在音符轨道悬停时显示精确落点，点击选中后再从面板选择音符。点击已有音符可选中其精确位置，即使它不在当前吸附线上。细分较密时画布自动展开，在轨道内横向滚动查看后续落点。
- 连打 5 / 大连打 6 显示为黄色长条；气球 7 / 特殊气球 9 为粉色 / 紫色带结绳气球；结束标记 8 为菱形。长音连接至后续 8，支持跨小节；缺少 8 时用虚线提示。创建长音须分别设置起点 5/6/7/9 和结束点 8，不自动插入结束点。
- 选中气球起点 7/9 后，可在“气球敲击次数”输入正整数，回车或移开焦点后保存到当前难度的 BALLOON 列表，支持撤销、草稿保存与导出。新增气球默认 5 次；删除气球会同步移除对应次数，保留后续气球的次数。原谱缺少次数时显示“未设置”。
- 显示网格与源码格数独立。混合细分时自动扩展源码至可精确表达新旧落点的公倍数，不移动原音符。单小节源码最多 65536 格，若混合细分超过此容量则拒绝添加并提示；并非无限精度的自由时间落点。
- 源码格数可调整为 4/8/12/16/24/32/48/64/96/192。不能精确保留已有音符位置时拒绝转换。
- 在循环范围输入框设置起止小节，播放时也可编辑。输入期间不验证、不改变当前播放范围；两个输入框之间切换焦点不会提前应用。按 Enter、点击“应用”或离开这组输入后才统一验证并应用；Escape 取消本次输入。超出范围的小节号自动限制到 1 至最大小节数，非整数或起止颠倒时明确提示。
- 应用循环范围后跳到该范围起始，原先正在播放则继续播放。点击“试听范围”启用循环，包含起止两个小节。音乐与咚咔音效使用同一循环边界，支持跨变速和变拍小节。
- 自定义循环范围不会随编辑小节的切换改变，小节导航顶部绿线标记循环范围。“循环范围设为当前小节”图标恢复跟随当前选择；右侧“试听本小节”仍仅循环当前小节。关闭“循环”后连续播放。
- 编辑时可平滑滚动；播放时采用分页跟随，页内音符保持原位，仅当播放头离开当前页时才立即跳到对应页，循环回跳也按页定位，不做卷轴平移动画。手动滚动会暂时关闭跟随，但不暂停播放；播放中的手动浏览使用即时定位，勾选“跟随播放”或重新开始播放即可恢复分页跟随。正在编辑源码时不自动切换编辑小节。可选 0.5/0.75/1/1.25 倍速，变速也会改变原曲音高。
- 音符提示音为鼓点合成音，1–4 播放对应咚咔，大音符更响；黄条 5/6 和气球 7/9 在起点至结束标记 8 之间按真实时间每秒 16 次播放咚，支持跨小节和范围循环，调整播放倍率后仍保持每秒 16 打。不是游戏原版音效，不模拟气球次数判定。
- 默认原曲音量为 60%、咚咔音量为 150%，保留清晰伴奏并突出音符声。咚咔音量可独立调整为 0–300%，不受原曲音量滑块影响。
- 咚咔发声时，背景音乐会轻压至当前原曲音量的 70%，50ms 后逐步恢复。关闭音符音、停止或暂停时取消压低；咚咔音量为零时不触发压低。
- 若播放时完全无声，请检查音符音开关、两个音量滑块、浏览器标签页、Windows 音量合成器和输出设备，也可在外部 Edge / Chrome 打开相同本机地址。
- Ctrl+Z 撤销，Ctrl+Shift+Z 重做，Ctrl+S 保存，Ctrl+Shift+S 另存为。
- 有效修改及未生效的错误源码会保存到各自谱面的浏览器草稿，音频不存入本地草稿。源码输入框内保留浏览器原生文本撤销；编辑器撤销按钮及非输入框内的快捷键操作谱面级历史。

## 支持范围

使用 tja 解析库读取语义，源码编辑层保留未编辑的小节、注释和元数据。支持多难度切换、Shift-JIS/UTF-8、普通单线谱面、小节起点及小节内部 BPMCHANGE / MEASURE / 正负 DELAY、GOGO 和数值 SCROLL。SCROLL 不改变波形时间轴缩放。

暂不支持分歧谱面、双人谱、复数或带方向的 SCROLL，以及其他未识别指令，遇到时拒绝加载，避免错误对齐。5–9 支持差异化图形、长音连接与气球次数编辑，不做完整游戏判定。Shift-JIS 编码检测是 UTF-8 校验失败后的回退，不覆盖所有历史编码。
