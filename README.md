# Web TJA Studio

基于 Vue 3 + Vite 的纯前端 TJA 波形与音符编辑器。谱面解析、编辑、历史与音频处理均在浏览器完成，无需后端接口，不上传文件。只有明确执行“保存”时才会写回关联的谱面文件，音频不会被修改。

仓库：[OurTaiko/web-tja-studio](https://github.com/OurTaiko/web-tja-studio) · 组织：[OurTaiko](https://github.com/OurTaiko) · 开源协议：[MIT](./LICENSE)，Copyright © 2026 Dafrok。顶部“设置”提供独立的“检测更新”项；“设置 → 关于”提供仓库、组织和协议链接，外部链接在新标签页中打开，不影响当前编辑会话。

## 启动

需要 Node.js 20.19+ 或 22.12+（当前使用 Node.js 24）。在本目录运行 `npm install`，然后运行 `npm run dev`（或 `npm start`）。浏览器打开终端打印的本机地址，默认 http://127.0.0.1:4173。端口占用时自动选择后续端口，开发时支持 Vue 热更新。

在“文件”菜单中点击“新建”创建仅含歌曲信息、不含任何难度的歌曲，再从左侧“难度与模式”创建所需谱面；也可通过“打开谱面”手动选择一份或多份 TJA。没有音频也可直接播放已有谱面音符音；通过“载入音频”手动选择伴奏。

## 界面语言

支持简体中文、English、日本語、繁體中文与 한국어。首次打开按浏览器语言偏好顺序匹配；无法匹配时使用简体中文，繁体中文的台湾、香港、澳门及 Hant 变体会匹配繁體中文。

顶层工具栏右侧“设置 → 界面语言”可展开语言选项，即时切换并标记当前选择；选中后、点击外部或按 Esc 会收起，支持键盘 Tab 导航。选择单独保存在 localStorage 的 `web-tja-studio-locale` 中，刷新后仍有效；选择“跟随浏览器”可恢复自动识别。语言设置不包含在谱面草稿中，切换语言不会修改谱面、文件名、歌曲信息、当前选择、播放状态或撤销历史。界面、辅助功能标签、画布提示、确认框和应用校验错误均支持翻译；操作系统的文件选择框及浏览器自身错误信息由浏览器决定语言。

翻译集中在 [src/locales.js](./src/locales.js)，以简体中文原文作为键，其余文案按 English、日本語、繁體中文、한국어 的顺序维护。带参数的文案使用完整句子和 `{p0}` 等占位符；[src/i18n.js](./src/i18n.js) 负责响应式翻译、参数插值、语言匹配及偏好保存。`node --test src/i18n.test.js src/useStudio.test.js` 检查文案完整性、占位符、语言回退、偏好持久化和编辑状态保持。

## 构建与结构

运行 `npm run build` 生成 `dist/`，再运行 `npm run preview` 验证构建。将 `dist/` 部署到任意 HTTP(S) 静态托管即可，也支持部署在子目录，无需 `/api/files` 或 `/media/` 接口。Node.js 仅供开发和构建使用；浏览器运行不需要 Node.js。不要直接双击构建后的 HTML，请使用静态文件服务。

[index.html](./index.html) 保留在根目录，作为 Vite 的标准构建入口；应用源码由它加载 [src/main.js](./src/main.js)。GitHub Pages 发布的是构建后的 `dist/`，不是源码入口的位置；`base: './'` 保证资源和 PWA 清单在项目子目录中正确解析。

- [src/](./src/)：应用源码、样式、原始图标及共置的单元测试。
  - [App.vue](./src/App.vue)：应用外壳、文件操作、播放与混音控制。
  - [TimelineEditor.vue](./src/TimelineEditor.vue)：Canvas 波形、时间网格、格子检查器与全局导航。
  - [MeasureEditor.vue](./src/MeasureEditor.vue)：小节源码、任意落点指令与指令列表。
  - [courses.js](./src/courses.js) / [CourseControls.vue](./src/CourseControls.vue)：难度与单人、P1/P2 分谱识别、增删和结构管理。
  - [BranchControls.vue](./src/BranchControls.vue)：统一路线分段按钮与可搜索、定位的逐处分歧设置。
  - [useStudio.js](./src/useStudio.js)：多谱面状态、兼容旧版本的本地草稿、Web Audio 调度与生命周期清理。
  - [history.js](./src/history.js)：可逆文本 diff，每份谱面最多保留 50 步编辑历史。
  - [metadata.js](./src/metadata.js)：歌曲元数据读取、验证与保留未编辑内容的修改。
  - [i18n.js](./src/i18n.js) / [locales.js](./src/locales.js)：五语言界面、校验提示、浏览器语言识别与独立语言偏好。
  - [chart.js](./src/chart.js) 等纯 JavaScript 模块：解析、分段时序、精确落点和音效逻辑。
- [public/](./public/)：直接复制到构建产物的 PWA 安装图标。
- [tests/](./tests/)：部署约束与 PWA 构建集成测试。
- [vite.config.js](./vite.config.js)：Vue、PWA 与静态构建配置，不提供本机文件读取接口，构建产物不包含本地谱面和音频。开发统一使用 `npm run dev`，不再提供独立的 Windows 启动脚本。
- 根目录只保留项目入口、依赖清单与锁文件、配置、说明和协议；构建产物与依赖目录不提交。

## PWA 安装与离线使用

生产构建包含 Web App Manifest、192/512 像素安装图标、Apple Touch 图标和 Service Worker。通过 HTTPS（本机可使用 localhost / 127.0.0.1）访问后，可在支持的 Chrome / Edge 中通过浏览器安装入口安装为独立窗口应用；iOS Safari 可使用“分享 → 添加到主屏幕”。入口显示和安装能力由浏览器决定，无需安装也能正常使用。

首次联网打开并等待应用资源缓存完成后，即可离线再次打开、编辑本地 TJA 和手动载入本地音频。缓存仅包含构建出的应用页面、脚本、样式、清单和图标，不缓存用户谱面或音频，也不读取服务器目录。草稿沿用现有浏览器本地存储；音频刷新后仍需重新载入，草稿不能替代文件保存。首次访问或缓存被浏览器清理后需要联网。

新版本在联网访问时后台下载，不会强制刷新正在编辑的页面。关闭该应用的所有标签页和独立窗口后，下一次打开使用已下载的新版本。PWA 与草稿按站点来源隔离，安装应用与同来源浏览器页面共用草稿。

“设置”菜单的第一个一级项“检测更新”检查当前部署的 Service Worker 版本，与语言、快捷键帮助、关于并列，不依赖 GitHub Releases。每次启动生产应用也会等待离线注册完成并自动检查；发现新版时显示非阻塞提示，可选择“更新并重启”或“稍后”，不会自动中断编辑。主动检测没有新版本时提示“已经是最新版本”，被动检测无更新时保持安静。

主动检测发现新版本或点击提示中的更新按钮后，确认更新并重启，也可取消并稍后重启。安装确认前后均检查保存状态；重启前将待应用的小节源码、无效源码及历史写入草稿，存储失败或仍在保存时不会重启。音频和文件句柄不会持久化，重启后需重新载入。网络、安装或超时错误会明确显示，不会被当成“最新版本”。开发服务器不自动检查，主动检测时提示使用生产版本。

开发服务器不启用 Service Worker，避免离线缓存干扰热更新；本机验证请运行 `npm run build` 和 `npm run preview`。保持 HTTPS 与正常的 JavaScript / JSON MIME 类型，静态服务应让 Service Worker 脚本及时重新验证，避免对其设置长期不可变缓存。

## GitHub Pages

仓库包含 `.github/workflows/deploy-pages.yml`，推送到 `master` 时自动构建并发布，也可在 Actions 中选择 **Deploy GitHub Pages → Run workflow** 手动发布。

首次部署前，在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。流程使用 Node.js 24，执行 `npm ci`、`npm run build`，通过官方 Pages Actions 上传并发布 `dist/`，不需要个人访问令牌，也不需要提交构建产物或创建 `gh-pages` 分支。

Actions 在 Node.js 设置和 `npm ci --registry=https://registry.npmjs.org/` 中显式指定公共 npm 源。锁文件的所有 tarball 地址均指向 `https://registry.npmjs.org/`；安装前运行 `node --test tests/deployment.test.js` 检查，避免意外提交本机镜像或私有源地址。此配置不更改开发者本机的 npm 源；依赖版本与完整性校验值保持锁定。若本机屏蔽公共源，可使用已有依赖运行测试与构建；公共源的实际下载安装需在可访问公共源的 CI 环境验证。

如果 **Settings → Environments → github-pages** 设置了部署分支限制，请允许 `master` 部署。

默认访问地址为 https://ourtaiko.github.io/web-tja-studio/ 。现有 Vite 配置使用相对资源路径 `base: './'`，可直接在该项目子路径下运行。部署成功后也可在工作流的 `github-pages` 环境中查看实际网址；构建失败时不会发布新版本。

## 谱面管理与历史

- 文件标签与下方编辑区属于同一面板，活动标签与编辑内容使用同一背景。关闭按钮仅在标签激活、鼠标悬浮或键盘焦点位于标签内时显示，隐藏时保留占位，避免标签宽度变化。标签可切换、关闭；编辑区不再显示文件名输入，使用“另存为”选择新名称与位置。同名文件会作为不同谱面打开。
- 文件标签始终单行显示，最大宽度为 320px；长文件名以省略号截断，悬停可查看完整名称，未保存星号和关闭按钮不参与截断。
- “＋”新建标签始终紧跟最后一个文件标签，靠左排列并随标签一起横向滚动，不固定在整栏右侧；点击即创建歌曲，未打开文件时位于最左侧。空标签栏不显示引导文字，空编辑区不再显示重复的产品标题或“谱面已关闭”等普通状态；操作错误仍明确显示。
- 歌曲尚未创建谱面时，主编辑区仅保留创建引导，不显示标题、统计、历史工具栏或普通状态；实际错误提示仍显示。
- 顶栏采用紧凑菜单栏：左侧仅保留小产品图标，旁边是“文件”“编辑”和“选择”，右侧只保留一个设置按钮，收纳检测更新、界面语言、快捷键帮助和关于。“关于”保留项目链接与版权，仅在草稿存储失败时显示草稿警告，不展示正常的草稿状态。点击内部文字或滚动条不会关闭，点击外部或用 Tab 将焦点移出时关闭，Esc 关闭当前弹框并返回入口。展开的菜单入口仅以背景色表示选中，不增加边框或底边标记。顶栏菜单紧贴触发元素的下边缘展开，靠近屏幕边缘时调整水平位置避免溢出；内容过长时内部滚动。设置菜单共用一个滚动面板，帮助文本上的滚轮滚动该面板，打开其他分组时收起原分组。
- 歌曲工作区的汉堡标题行整行可点击，展开时右侧显示收起箭头。桌面收起后保留 44px 一级图标栏，点击“歌曲信息”或“难度与模式”图标自动展开并定位。屏幕宽度不超过 900px 时默认收起，只在编辑区顶部保留一行汉堡入口，不占用左侧图标栏；展开后覆盖下方编辑区，保留顶部菜单和文件标签可见且可操作，可切换文件、修改歌曲信息、难度和模式。编辑区此时禁止交互和编辑快捷键，再次点击标题行或按 Esc 收起后恢复；创建、删除谱面对话框仍可独立操作。
- “设置 → 快捷键帮助”按文件、编辑与播放、时间轴导航分组列出实际支持的按键，并注明输入框、选中位置及焦点的使用条件。无需打开谱面即可查看，窄屏可滚动阅读。
- Ctrl+Alt+W 关闭当前谱面标签，长按不会连续关闭；输入框聚焦时也可使用，会先提交失焦生效的字段和待应用源码，再按正常规则确认关闭。创建、删除等确认弹窗内不触发该快捷键，请先完成或取消弹窗。不拦截浏览器的 Ctrl+W / Ctrl+Shift+W。
- 谱面标签超出宽度时，鼠标滚轮可左右滚动（兼容触控板横向滚动）；悬浮半透明滚动条仅在鼠标进入、键盘聚焦或拖动时显示，不占用标签布局。可拖动滑块、点击轨道，或聚焦滚动条后用左右键、PageUp/PageDown、Home/End 导航；无溢出时不影响页面正常滚动。
- 每份谱面独立保留编辑内容、当前难度、正在查看的小节、音频及撤销/重做历史；音符选择与小节区间在当前页面内按文件独立保留，刷新后不恢复选择。切换时暂停播放，待应用的源码会先尝试同步；错误源码保留在原标签，不影响其他谱面编辑。
- 每份谱面最多保留最近 50 步有效编辑，以可逆文本差异保存，不为每一步复制整份谱面。撤销后进行新编辑只清空当前谱面的重做分支；切换难度不会清空历史。撤销与重做按钮固定在主编辑区顶部，空谱面也可操作；不再显示历史步数或文件关联状态。
- 有效编辑、未生效的源码及历史自动保存到当前浏览器的本地工作区。启动或刷新时自动恢复所有谱面，无需手动恢复；兼容原有单谱面草稿。音频仅在当前页面内存中保留，刷新或恢复后需重新载入。
- 星号表示存在未保存的修改或无效源码。新建且未编辑的谱面不显示星号，可直接关闭；撤销回新建时的初始内容也会清除修改标记。实际编辑、修改文件名或存在无效源码时，关闭会先确认；确认后会同时移除该谱面的本地草稿和历史。保存期间不能关闭对应谱面。草稿不替代文件保存，本地存储不可用或空间不足时会提示，请及时保存文件。

## 保存与另存为

- 顶栏的“文件”菜单收纳新建、打开谱面、载入音频、保存、另存为和关闭谱面，有快捷键的操作在右侧显示按键；未打开歌曲时禁用载入音频，打开后为当前标签载入。保存与另存为只作用于当前文件。文件标签栏只负责切换与关闭，不放置保存按钮。窄屏菜单保留完整操作名称与快捷键。
- “编辑”菜单复用撤销/重做、音符设置与清空、复制/粘贴、前后插入/删除/清空小节；音符图标与右侧面板共用同一套符号。“选择”菜单收纳小节区间与音符选择，Ctrl+A 选择全部小节，Ctrl+Shift+A 选择正在查看的小节。音符编辑需先选择位置；无谱面、无选择、无历史或源码无效时按对应操作禁用。输入框仍保留原生快捷键。
- Ctrl+Alt+N 新建歌曲，Ctrl+O 打开一份或多份谱面（macOS 也支持 Command+O）。输入框聚焦时同样生效，先提交失焦生效的字段并保留待应用源码；长按不会重复触发，确认弹窗与输入法组字期间不拦截。不接管浏览器的 Ctrl+N 新窗口快捷键。
- 可将一个或多个 `.tja` 文件直接拖到窗口任意位置打开，扩展名不区分大小写，按拖入顺序新增标签，不覆盖已打开文档。也可拖入一个音频，载入当前谱面；谱面与音频一起拖入时先打开谱面，再将音频载入最后打开的谱面。一次多个音频会提示并拒绝载入音频。不支持的文件会明确提示，确认弹窗打开时禁止拖入切换，普通文字拖动不受影响。
- Android 的系统文件选择器可能无法将未知的 `.tja` 扩展名映射到筛选 MIME 类型，导致文件不可选。打开选择器不再限制扩展名或 MIME，选择后由应用校验 `.tja` 扩展名；`application/octet-stream` 或空 MIME 的 TJA 也能打开。选择其他文件会明确提示，不会覆盖现有谱面。保存选择器仍保留 TJA 类型和 UTF-8 BOM 编码。
- 不合法文件、谱面解析失败或文件读取失败使用模态框显示文件名与原因，不写入左上角的编辑状态提示。多文件载入的错误逐条展示，不被后续成功载入覆盖；关闭按钮或 Esc 确认提示。取消系统文件选择器不作为错误，已有谱面与编辑历史保持不变。
- 未打开文件时，占位区提供“新建谱面”按钮；已有歌曲但尚无谱面时，提供简单、普通、困难、魔王、里魔王五个按钮，点击即在当前歌曲中创建对应难度的单人空谱面，保留歌曲元数据并支持撤销。
- 在支持 File System Access API 的 Chrome / Edge 中，通过“打开谱面”选择的文件会与当前标签关联。“保存”（Ctrl+S）写回关联文件；“另存为”（Ctrl+Shift+S）选择新的文件位置，成功后将当前标签关联到新文件，不另开标签。新建谱面首次保存也会选择位置。
- 文件系统接口需要安全上下文（HTTPS 或 localhost）及浏览器授权。文件句柄不会写入浏览器草稿；刷新或恢复后，首次保存需要重新选择位置。
- 保存统一使用带 BOM 的 UTF-8，包括原为 Shift-JIS 的谱面；直接保存会将原文件转换为此编码。另存为可保留原始文件。文件名不再自动附加 edited。
- 只有写入并关闭文件流成功后才标记为已保存。取消、权限拒绝或写入失败会保留修改；检测到磁盘文件已变化时会先确认是否覆盖。保存期间可继续编辑或切换标签，后续修改不会误标记为已保存。撤销/重做到最近保存的内容会相应更新星号。
- 不支持此接口的浏览器通过下载副本保存，不会写回原文件；“另存为”会先询问文件名，路径由浏览器下载设置决定。由于无法确认下载是否完成，会明确提示并保留未保存标记，请确认副本已下载后再关闭。
- 两个保存快捷键在源码和其他输入框聚焦时也生效，保存前会同步待应用的有效源码；无效源码会阻止保存，不会用旧内容覆盖文件。

## 音频与无伴奏播放

- “载入音频”位于当前谱面编辑区的播放控制栏最右端，在速度、音量之后，只为当前标签载入伴奏；未打开谱面时不可用。切换标签会恢复各自的音频，不会将伴奏应用到所有谱面。
- 播放栏随中间编辑区宽度布局：宽度不超过 640px 时，播放与时间占第一行，速度和音量紧邻靠左、载入音频靠右占第二行；不超过 400px 时音量与音频按钮只显示图标，保留可访问名称和悬停提示。速度提供 0.25、0.5、0.75、1、1.25、1.5、1.75、2 倍档位。音量浮层始终限制在编辑区内，短屏可内部滚动。
- 播放栏始终吸附屏幕底部：桌面位于中间编辑区底部，移动端独立固定在视口底部，滚动到右侧指令或源码区也不会消失。页面预留播放栏的实际高度，避免遮挡末尾内容，并适配设备底部安全区；展开移动端侧栏时播放栏仍可操作，侧栏在其上方结束。
- 无需音频即可播放、暂停、定位、变速和试听小节，普通音符及长音使用相同的合成音效。选择小节区间后自动重复该区间；没有区间时在谱面最后一个时间分段结束时停止。关闭音符音或把咚咔音量调为零时仅运行播放头。载入伴奏后仍以音频时长为播放边界。
- 不再提供文件夹关联或 WAVE 自动匹配；WAVE 仍作为谱面元数据保留、编辑和保存，不会触发文件读取或网络请求。伴奏统一通过“载入音频”手动选择。
- 手动载入的音频按文件标签独立保留，切换标签会恢复该文件的伴奏；刷新或恢复草稿后需重新载入。修改 WAVE（包括撤销/重做）会清除旧伴奏，需手动选择对应音频。
- 音频读取或解码失败时通过模态框明确提示，不替换原有伴奏，仍可无伴奏播放。载入音频会暂停播放，完成后可重新播放；所选文件只在本地读取，不上传或修改。

## 复制与粘贴小节

- “编辑 → 复制小节”或 Ctrl+C 复制选中的小节区间；未选择区间时复制正在查看的小节，不改变查看位置、选择、播放位置或历史。复制包含音符、显式指令与气球次数，沿当前显示路线提取，不复制分歧结构或其他路线。
- “编辑 → 粘贴小节”或 Ctrl+V 打开粘贴方式对话框：从正在查看的小节开始覆盖，剩余小节不足时在该路线末尾续接；或在查看小节之前插入新小节。覆盖跨越分歧边界时弹框显示警告并拒绝操作，不修改谱面；可以缩短复制区间或改用插入。其他路线、难度与分谱保持不变。
- 粘贴是一项可撤销的完整操作，保留气球次数，并按插入位置调整既有小节选择；旧音符选择清空。指令按粘贴后的上下文正常继承，不修改音频本身。无效源码阻止复制和粘贴。
- 小节剪贴板只存于当前页面内存，可在文件标签之间共用，刷新后清空，不读取或写入系统剪贴板。输入框、可编辑文本、对话框与快捷键帮助保留原生复制、粘贴、全选操作；macOS 也支持用 Command 代替 Ctrl。

## 插入小节

- 时间轴上方工具栏提供带方向图标的“前插小节 / 后插小节”连体按钮组，共享外框并以中线分隔。在当前小节前后插入一个 16 格空白小节，暂停播放并选中新小节，支持保存、草稿恢复、撤销与重做。尚未创建难度谱面时不显示时间轴工具栏，源码无效时按钮不可用。
- 插入沿用所在边界的 BPM、拍号、卷轴速度、Go-Go 与小节线状态，不复制音符、气球次数或指令。前插位于当前小节的起始指令之后，后插位于下一小节起始指令之前；原有指令只执行一次。后续谱面时间随新增小节顺延，伴奏本身不修改或插入静音。

## 删除小节

- 时间轴工具栏的“删除小节”直接删除当前小节及其音符、起始和内部指令，不弹确认框；不删除分歧边界或共用指令。只剩一个小节或源码无效时不可用，与“清空本小节”（保留小节）不同。
- 删除后暂停播放，选中原位置的下一小节；删除末尾时选中前一小节。后续小节前移，循环范围保留原有未删除小节；若删除循环范围内唯一小节则取消自定义范围。伴奏不裁剪。
- 分歧内仅删除当前路线的小节，不对齐其他路线时长。同步移除该小节对应的气球次数，保留其余路线、难度及玩家内容；支持保存、草稿恢复和撤销/重做，撤销同时恢复小节选择与循环范围。
- 分歧内仅扩展当前路线，其他路线不补齐；共用段插入保持共用。其他难度、多人分谱及文件不变。自定义循环范围按原有小节顺移，插入到范围内部时包含新小节；撤销与重做同时恢复选择及循环范围。
- 分歧路线栏在标题下方直接显示当前分歧编号、路线与条件，或“当前位于共用段”；不再显示独立的说明文案或底部信息行。

## 紧凑工作区与歌曲信息

- 下方“全局导航”在小节按钮上方依次展示小节数量、咚与咔音符数量、连打秒数，以及合并的“气球 / 特殊连打”要求敲击次数之和。中间编辑区标题栏在曲名左边显示难度图标、右边显示模式，并保留编码及撤销/重做；右侧面板不再重复难度和模式。统计仅包含当前难度、模式与所选分歧路线；大音符及双人合打各算一个音符。连打时长按谱面时间计算，包含变速与延迟，不随播放速度改变；未结束的连打按时间轴逻辑计至下一个长音或谱面末尾。气球与特殊连打共用 BALLOON（含路线专用字段），按源码顺序匹配次数后合并显示；任一使用中的次数未设置或无效时显示“未完整设置”，不以零替代；多余的未使用次数不计入。

- 产品图标为内含心电图式不规则波形的红色“咚”音符，用于应用标识与浏览器标签页，产品名称统一为 Web TJA Studio。工作区无外围留白与卡片圆角，标签和编辑区横向贴齐浏览器边缘，仅在控件内部保留必要间距。顶部不显示产品标题和副标题，默认不展开歌曲信息与音量面板，为谱面轨道留出空间。
- UTF-8 / Shift-JIS 编码标记紧跟曲名，与曲名作为一组排版；曲名过长时仅截断曲名，编码不会被统计信息隔开。
- 展开左侧工作区的“歌曲信息”，可编辑 TITLE、SUBTITLE、ARTIST、GENRE、WAVE、基础 BPM、OFFSET 和 DEMOSTART。每个字段失焦后验证并作为一次可撤销编辑保存到谱面与草稿；Ctrl+S / Ctrl+Shift+S 会先提交当前输入框，再保存 / 另存为，校验失败时不保存。
- 信息分为“基本信息”和默认收起的“多语言信息”；后者支持中文、英语、日语、韩语的曲名及副标题，分别写入 TITLEZH / TITLEEN / TITLEJA / TITLEKO 及对应的 SUBTITLE 字段。各语言独立，不覆盖基础 TITLE / SUBTITLE，也不会随界面语言改写歌曲内容。
- 元数据修改保留其他字段、注释、换行格式和各难度源码。清空可选字段会移除对应的全局定义。DEMOSTART 仅修改 TJA 的试听起点元数据，不会改变编辑器的播放位置。
- 更改 WAVE 会暂停播放并解除旧音频；撤销或重做 WAVE 修改也会解除伴奏。需要伴奏时请手动载入对应音频，未载入时仍可无伴奏播放。
- 桌面编辑器分为左侧歌曲工作区、中间主编辑区、右侧小节编辑三栏，各栏独立滚动。音乐播放栏固定在中间区域底部，不随编辑内容滚走，也不会覆盖右侧小节编辑；音量面板向上展开。窄屏按工作区、主编辑区、小节编辑顺序纵向排列，播放栏在主编辑区内吸底。
- 左侧使用紧凑的汉堡工具栏，不显示重复的工作区大标题或自动应用说明；下方提供“歌曲信息”与“难度与模式”。页面不再有单独底栏，顶部设置按钮仅在草稿存储失败时显示红点，并在“关于”中显示警告；草稿自动保存与恢复机制保持不变。
- 点击“音量”调整音乐音量、咚咔音量和音符音开关，不再提供独立试音按钮。合成混音仍经过动态压缩以降低过载风险。

## 编辑

- 左侧独立歌曲工作区包含可展开的“歌曲信息”和“难度与模式”，两项共享相同的标题字号、字重、间距、图标和展开箭头样式，可以独立纵向滚动；窄屏时仅保留顶部汉堡行，展开仅覆盖下方编辑区。“难度与模式”整体和各难度分组默认展开，均可点击标题收起。难度树提供五种难度的单人、多人 - P1、多人 - P2，缺失项弱化显示并带加号标记；导入的其他难度及多人共用谱也会保留显示。已有分谱点击后直接编辑，正文、气球、指令与试听只针对当前分谱，保存始终包含整份 TJA。
- 难度名称跟随界面语言；简体中文为简单 / 普通 / 困难 / 魔王 / 里魔王，TJA 中的 Easy / Normal / Hard / Oni / Edit 标识不变。难度图标使用原创 SVG：简单为橙红小花、普通为绿色竹子、困难为蓝色松树、魔王为粉紫怪物、里魔王为深紫怪物，并非太鼓原版素材；图标集中在 [DifficultyIcon.vue](./src/DifficultyIcon.vue)。自定义难度保留原名并显示通用音乐图标。右侧编辑区标题左侧显示当前难度图标与名称，右侧显示单人 / 多人及具体声部，切换时同步更新。
- 已有谱面的模式行在名称后显示 ★n；已有谱面未设置有效星级时显示 ★—，不存在的谱面不显示星级。点击缺失项会确认创建该难度和模式的空白谱面，取消不修改内容或选择。默认 1 星；多人另一方已存在时沿用其星级，但不复制音符、气球或指令。创建 P1 不会顺带创建 P2，反之亦然。
- 当前选中谱面的星级在上方难度、模式旁显示为 ★n，十颗星的末尾不再显示重复的数值。十颗星可点击或横向拖动，也支持方向键及 Home / End；Easy / Normal / Hard / Oni / Edit 上限依次为 5 / 7 / 8 / 10 / 10 星，不可选的星星显示灰色。单人星级独立；同一难度的多人分谱共享星级，调整任意 P1 / P2 都会同步更新另一方及共用多人谱的 LEVEL，不影响单人或其他难度。拖动时上方数值同步预览，松开后形成一次可撤销修改，取消拖动不改源码。导入时不自动改写原有 LEVEL；主动选择星级后会同步已有多人分谱。
- 已有模式行最右侧在鼠标悬停或键盘聚焦时显示小 ×，触屏上常显；点击后弹窗确认，仅删除该行谱面，删除 P1 不影响 P2。删除非当前行不会切换正在编辑的谱面或重置其选点、分歧路线及循环范围。允许删除最后一张谱面；此时保留歌曲元数据，核心编辑区显示创建引导，并保留撤销、重做入口。仅含歌曲信息的 TJA 也能保存、另存为和恢复草稿，新增及删除谱面均可撤销恢复。
- 展开侧栏“歌曲信息”编辑歌曲元数据，字段失焦时自动应用并形成一次可撤销修改；校验错误明确提示。Ctrl+S / Ctrl+Shift+S 会先提交当前元数据输入框，校验失败时不保存。修改 WAVE 会解除旧伴奏，需要手动载入对应音频。
- 单人、P1/P2 谱面统一在左侧“难度与模式”创建和管理，右侧不再提供重复的双人结构入口。STYLE 和 START 是完整分谱结构，不能插进小节内部。
- 源码 A / B 表示双人咚 / 双人咔，可从音符面板选择，或在选中格子后分别按不带修饰键的 `-` / `=` 输入。A / B 字母键不再输入双人音符，A 改用于前移选择。显示带 2P 标记的大音符，并支持精确选点、统计和打击音；双人声部分别试听，不模拟双人同步判定。音符面板及源码支持 0–9、A、B。音符按钮按可用宽度自动分列并等宽撑满，列宽至少 60px、按钮高度保持 60px，空间不足时自动换行；图标统一使用 34×28px 占位、名称预留两行并在区域内垂直居中，避免单行文字偏上，同时保留大小音符本身的造型区别。完整名称与快捷键保留在悬停提示和辅助功能标签中。
- 波形和音符轨道共用音乐时间轴。TJA 时间转换为音乐时间时减去 OFFSET。
- “歌曲信息”中的“基础 BPM”修改全曲头部 BPM，不覆盖已有 BPMCHANGE。右侧“指令编辑”分为“任意落点指令”和“小节级指令”：BPMCHANGE、SCROLL、GOGOSTART/GOGOEND、正负 DELAY、LYRIC 和 SENOTECHANGE 写入选中的精确落点；MEASURE、BARLINEON/BARLINEOFF、SECTION 和 LEVELHOLD 的控件始终读取并修改当前小节起点，不受落点选择影响，也不移动选中的音符或指令位置。均支持撤销、草稿保存与导出。
- 右侧编辑面板最上方为“音符编辑”按钮区，下方依次为“当前选择的位置”“小节属性”“指令编辑”“本小节指令”“小节源码（含指令）”，使用统一标题和分隔线；小节内位置的分数和时间独立于指令分组，与时间轴选点同步，也可直接修改以选择音符或指令落点。“任意落点指令”“小节级指令”仅作为指令编辑的次级分组。小节编号与时间、源码格数归入小节属性，分歧控件归入小节级指令。位置与指令区输入框、下拉框统一为 32px 高并撑满各自参数列；歌词独占一行，位置和拍号的分子、分母在同一参数区域内等分宽度，复选框保持独立的小尺寸。
- 分歧按钮统一显示“普通 / 玄人 / 达人”，源码仍使用 N/E/M；右栏不再显示重复的音符统计，全局导航中的谱面统计保留。
- 在小节级指令中选择 p（精度）、r（连打数）、s（分数）即可在当前小节开头开始分歧，原有当前及后续共用小节成为默认 N 路线，阈值修改自动生效。N/E/M 按钮表示路线是否存在，新增路线先含一个空小节；再次点击确认删除该路线及其音符。取消最后一路时，移除分歧开始、路线与结束指令，将该路线保留为共用小节；条件选择“不启用”时同样关闭分歧，保留当前查看路线、移除其他路线（多路线时需确认）。路线显示仍由全局导航切换。后续分歧小节可插入 BRANCHEND，该小节及当前路线后续内容恢复共用，其他路线不截断、不补齐；无分歧或分歧首小节不能插入结束。操作支持撤销、重做与草稿恢复，保留气球次数。
- 既有源码中的小节内部指令不会因分组而自动迁移；仍可通过指令列表定位、删除或直接编辑源码。小节级控件只修改起点的同类指令，不覆盖内部指令。
- “小节线”可选择显示或隐藏，分别写入 BARLINEON / BARLINEOFF，并持续影响后续小节线。小节内部或末端的开关不会反过来隐藏已经出现的当前小节线。编辑用的细分网格、小节编号与指令定位标记仍保留，方便定位隐藏线上的音符；这不是游戏画面的完整模拟。
- 两组指令均在更改后自动生效。LYRIC、SECTION、LEVELHOLD、SENOTECHANGE 仅写入源码并标注位置，不模拟歌词叠加、判定重置、锁定路线或音符读音。LYRIC 可留空以清除歌词，使用字面量 `\n` 表示换行，不接受实际换行或 `//`；SENOTECHANGE 接受 1–12。未修改的同类指令（包括同点多条歌词）不会因应用其他参数而合并或丢失。重置按钮仍只清除当前落点的计时与显示参数，这四种指令通过取消勾选或列表垃圾桶删除。

- 有效修改及未生效的错误源码会保存到各自谱面的浏览器草稿，音频不存入本地草稿。源码输入框内保留浏览器原生文本撤销；编辑器撤销按钮及非输入框内的快捷键操作谱面级历史。

## 支持范围

使用 tja 解析库读取语义，源码编辑层保留未编辑的小节、注释和元数据。支持难度增删、单人及双人 P1/P2、Shift-JIS/UTF-8、普通单线及分歧谱面、小节起点及小节内部 BPMCHANGE / MEASURE / 正负 DELAY、GOGO、数值 SCROLL 和 BARLINEON/OFF。SCROLL 不改变波形时间轴缩放。

### 分歧谱面

- 载入含 BRANCHSTART / N / E / M 的谱面后，分歧路线栏在主编辑区贴边显示，没有卡片外边距或圆角边框，仅保留紧凑内边距和底部分隔线。栏中独立显示分歧总数、当前分歧及 N/E/M 分段按钮，一次切换全部分歧。需要混合路线时打开“逐处设置”弹窗，可搜索编号或判定条件，分别选路或定位到小节；混合选择显示“自定义路线”标记。若某处分歧没有对应路线，统一选项禁用，不自动生成缺失路线。空分歧不影响统一选择。分段控件使用原生单选框，支持键盘方向键和焦点提示；窄屏会换行，不将所有分歧铺在编辑区中。
- 每次只显示、编辑和试听所选路线，与前后共用小节组成完整时间轴，不会把三条路线依次拼接。默认选 N；谱面省略 N 时选实际存在的首条路线。单人和双人分谱分别解析其内部的分歧，不串联另一声部的内容。
- 支持 p / r / s 条件原样保留、显式 BRANCHEND、下一处 BRANCHSTART 隐式结束前一处分歧，以及到 END 才结束的分歧。各路线的小节数和结束时间均可不同；共用段及下一处分歧从所选路线的实际结束时间继续，不补齐、裁剪或强行拉齐。重复路线、未完成小节及无效参数仍会明确报错，包含未选路线，不会忽略错误继续载入。
- 路线从同一分歧起点及参数状态开始，BPM、拍号、延迟、Go-Go、卷轴和小节线不会从上一个源码路线串入下一个路线。合流后继承所选路线的最终参数；时间轴显示 N / E / M 标识，并以黄色标出分歧起始线。
- 切换路线暂停播放并定位到对应分歧，清除旧音符选择与循环范围，不修改谱面内容或增加撤销记录。路线选择随当前文档草稿保存，标签之间互不影响；切换难度时重新选择该难度的默认路线。音频仍属于原谱面，不会因切换路线丢失。
- 音符、落点指令、细分、气球次数和小节源码仅改动对应源码位置，保存始终包含所有路线、注释和原始条件；各路线共享谱面级撤销/重做历史。BALLOON 按所有路线的源码顺序计数，跳过未选路线时仍保留它们的次数。存在 BALLOONNOR / BALLOONEXP / BALLOONMAS 时，对应分歧内部使用各自的次数列表，共用段使用 BALLOON。
- 分歧边界及跨边界的共用指令不纳入路线小节源码或参数重置，避免编辑单条路线时误删结构。条件、阈值、N/E/M 路线增删与结束位置统一通过图形控件修改，不再提供整段分歧源码弹窗或对应的铅笔入口。
- 小节级条件控件在当前共用小节开头插入 BRANCHSTART 与默认 N，不受选中音符落点影响；原有小节纳入 N，不额外复制或新增 N 小节。尚未插入 BRANCHEND 的路线延续至下一处分歧或谱面末尾。
- 图形化分歧修改作为一次谱面历史记录保存，可撤销、重做、草稿恢复和导出；该操作的撤销/重做会恢复当时的路线选择。其余分歧的选择按位置顺延；所选路线被移除时明确提示并切换到可用路线。结构变更暂停播放并清除旧格子、循环范围。
- 结构变更同步维护 BALLOON 及按路线分开的次数池，保留其余路线与后续气球次数。
- 试听按手动选择的路线播放，不根据命中率、连打数或得分自动判定。SECTION / LEVELHOLD 等游戏判定命令仍保留并提示，不宣称完整模拟游戏行为。

按 [TJA 指令说明](https://github.com/269Seahorse/Better-taiko-web/blob/master/TJA-format.mediawiki) 核对后的支持边界：

| 指令 | 当前支持 |
| --- | --- |
| START / END / STYLE | 难度增删、Single / Double / Couple 识别、P1/P2 分谱切换与创建，保存全体声部 |
| BPMCHANGE / MEASURE / DELAY | 分段时间计算、落点编辑、列表、时间轴与导出 |
| SCROLL / GOGOSTART / GOGOEND | 参数继承、落点编辑与标注；Go-Go 区域着色，不模拟游戏滚动和计分 |
| BARLINEON / BARLINEOFF | 默认显示，按源码顺序继承；编辑、显隐、定位、删除、撤销、草稿与导出 |
| LYRIC / SECTION / LEVELHOLD / SENOTECHANGE | 落点控件增删改、准确定位、列表、时间轴及导出；不模拟歌词叠加、分歧判定或音符读音 |
| BMSCROLL / HBSCROLL（START 前） | 保留原文并提示，不模拟游戏滚动模式 |
| BRANCHSTART / BRANCHEND / N / E / M | 整段源码创建/修改结构与条件、切换路线、准确时序、编辑与试听；保存全部路线，不模拟游戏判定 |
| NEXTSONG / DIRECTION / SUDDEN / JPOSSCROLL 等扩展指令 | 未实现；在谱面体内遇到未识别指令时明确拒绝加载 |

含“仅保留”的指令时，页面持续显示提示，不将其宣称为已实现的游戏效果。它们参与小节源码、准确定位和细分转换，避免编辑其他音符时移位或丢失。重置落点参数不会顺带清除这些指令；需要删除时使用对应指令的垃圾桶或直接编辑源码。

气球头字段按当前分谱继承，写入时隔离当前和后续声部，避免 P1 的修改串入 P2。

暂不支持复数或带方向的 SCROLL，以及其他未识别指令，遇到时拒绝加载，避免错误对齐。5–9 支持差异化图形、长音连接与气球次数编辑，不做完整游戏判定。Shift-JIS 编码检测是 UTF-8 校验失败后的回退，不覆盖所有历史编码。
