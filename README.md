# 咚咔绘板 · DonKanvas

支持**手机、平板和桌面**的在线 TJA 太鼓谱面编辑器。通过 Canvas 波形与音符时间轴制谱，兼顾触屏手势和键盘快捷键；谱面、音频与历史均在浏览器处理，不上传文件，无需后端。

[在线编辑器](https://ourtaiko.github.io/DonKanvas/) · [应用介绍](https://ourtaiko.github.io/DonKanvas/about.html) · [GitHub](https://github.com/OurTaiko/DonKanvas) · [MIT](./LICENSE)

支持简体中文、繁體中文、English、日本語和 한국어。对应产品短名为咚咔绘板、咚咔繪板、DonKanvas、ドンカッボード、동캇보드；非英文页面首次展示使用「本地名 · DonKanvas」。语言可在“设置 → 界面语言”切换，也可跟随浏览器。

## 本地运行

需要 Node.js 20.19+ 或 22.12+；部署工作流使用 Node.js 24。

```sh
npm ci
npm run dev
```

打开终端显示的地址，默认 http://127.0.0.1:4173；端口占用时自动递增。`npm start` 等同于开发命令。

```sh
npm run build
npm run preview
```

构建产物位于 `dist/`。浏览器运行不需要 Node.js；请通过 HTTP(S) 静态服务访问，不要直接双击 HTML。

## 基本使用

1. **创建或打开**：“文件 → 新建”创建歌曲，再在“难度与模式”中添加谱面；“打开谱面”可选择多份 TJA，也支持拖入文件。
2. **编辑**：点击音符网格选择落点，再点音符按钮或按快捷键写入。侧栏可编辑歌曲信息、小节源码、指令及气球次数，支持难度、P1/P2 和分歧管理。
3. **试听**：可直接播放合成音符音；伴奏需通过“载入音频”手动选择。播放栏提供速度、原曲音量、咚咔音量与跟随播放控制。
4. **保存**：保存当前整份 TJA，包括所有难度、声部与路线。草稿自动保存在本地，但不能替代文件保存。

手机与平板自动适配横竖屏；窄屏通过标签切换编辑、落点、导航与分歧面板。

### 手势与快捷键

| 操作 | 手势或按键 |
| --- | --- |
| 浏览时间轴 | 滑动、鼠标滚轮、触控板；拖动全曲总览 |
| 精确微调选点 | 音符网格长按约 450ms 后左右滑动；A / D |
| 定位、试听 | 点按波形定位；长按波形试听；空格播放 / 暂停 |
| 设置音符 | 1–9；`-` / `=` 输入双人咚 / 咔 |
| 清空落点 | 0 / Delete / Backspace |
| 调整吸附、跳转播放头 | W / S；Q / E |
| 选择循环区间 | F 两次标记首尾；Shift+单击或拖选导航小节 |
| 清除小节区间 | Shift+F |
| 复制 / 粘贴小节 | Ctrl+C / Ctrl+V |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z |
| 保存 / 另存为 | Ctrl+S / Ctrl+Shift+S |

macOS 的文件、剪贴板和历史组合键也支持 Command。完整列表和焦点条件见“设置 → 快捷键帮助”；输入框保留原生文字编辑和输入法行为。

**查看小节、音符选点和小节区间相互独立**：单纯查看不移动播放头、不暂停或清除选择；只有明确选择小节区间才重复播放。复制使用所选区间，无区间时使用正在查看的小节；粘贴可覆盖或前插，不复制分歧结构，跨分歧边界覆盖会被拒绝。

### 文件、音频与草稿

- 支持 UTF-8 和 Shift-JIS 导入；**保存统一转换为带 BOM 的 UTF-8**。需要保留原编码文件时请另存为。
- 支持文件系统接口的 Chrome / Edge 可在 HTTPS 或 localhost 下授权写回文件。其他浏览器下载副本，无法确认下载完成，因此保留未保存标记；请确认副本后再关闭。
- 文件写入成功才标记已保存；取消、权限拒绝、写入失败或无效源码不会丢弃修改。磁盘内容变化时会确认覆盖。
- 多文件独立保留内容、伴奏与最多 50 步撤销历史。草稿自动恢复；刷新后音频和文件写回授权需重新载入，选择状态不恢复。
- WAVE 仅作为元数据保留，不自动读取文件、匹配目录或请求网络。修改 WAVE（包括撤销 / 重做）会解除旧伴奏。
- 音频不上传、不修改、不写入草稿；未载入伴奏也能试听。存储空间不足或不可用时会明确提示，请及时保存。

## 支持与限制

- 支持难度增删、单人及双人 P1/P2、普通单线与 N/E/M 分歧谱面；保存保留未编辑的内容、注释与元数据。
- 支持小节起点及内部 BPMCHANGE、MEASURE、正负 DELAY、数值 SCROLL、Go-Go、小节线，以及 LYRIC / SECTION / LEVELHOLD / SENOTECHANGE 的编辑和导出。
- 分歧只显示和试听所选路线，所有已存在路线必须具有相同小节数和实际时长。导入不一致时需确认修复，否则拒绝载入；修复不直接覆盖原文件。
- 分歧内 BPM、拍号、延迟在各路线对应落点同步；音符、非计时指令和气球次数保持路线独立。结构操作支持撤销与草稿恢复。
- 自定义吸附支持每小节 1–768 等分；精确编辑按需要扩展源码，单小节最多 65536 格。无法无损转换或超过容量时拒绝编辑。
- 长音需分别设置起点 5/6/7/9 与结束点 8；缺失结束点会提示。音符音为合成音，不是游戏原版音效。
- 时间轴不模拟游戏卷轴、计分、分歧自动判定或双人同步判定。BMSCROLL / HBSCROLL 仅保留并提示；复数 / 带方向 SCROLL、NEXTSONG / SUDDEN / JPOSSCROLL 等未实现指令会拒绝载入。
- 负延迟可能产生重叠落点；负音乐时间可编辑与导出，但播放从 0 秒开始。调整试听速度也会改变伴奏音高。

## PWA 与离线

生产版本可通过支持浏览器的原生安装入口安装；iOS Safari 使用“分享 → 添加到主屏幕”。**应用不显示自定义安装提示**，Chrome 地址栏安装入口是否出现由浏览器决定。

安装后默认请求 `fullscreen`，不强制普通标签页全屏、不锁定方向。浏览器可回退显示模式，iOS/iPadOS 不保证隐藏系统状态栏；已有安装可能需要重新安装才应用显示模式更新。

首次联网并完成应用资源缓存后，可离线打开、编辑本地谱面和载入本地音频。缓存不含用户文件；首次访问或缓存被清理后仍需联网。安装窗口与同来源浏览器页面共用草稿。

生产应用启动时自动检查更新，发现新版后提示“更新并重启”或“稍后”，不会强制中断编辑；也可使用“设置 → 检测更新”。重启前保存草稿，保存进行中或草稿存储失败时不重启。音频和文件授权需重新载入。开发服务器不启用 Service Worker，PWA 验证请使用生产构建与预览。

## 部署与搜索收录

将 `dist/` 发布到 HTTPS 静态托管即可。相对资源路径 `base: './'` 支持子目录；保持正确的 JavaScript / JSON MIME 类型，不要给 Service Worker 脚本设置长期不可变缓存。

### GitHub Pages

1. 在仓库 **Settings → Pages → Source** 选择 **GitHub Actions**。
2. 推送到 `main`，或手动运行 [Deploy GitHub Pages](./.github/workflows/deploy-pages.yml)。
3. 如配置了 `github-pages` 环境部署分支限制，允许 `main`。

工作流从公共 npm 源安装锁定依赖，构建并发布 `dist/`；无需个人访问令牌、`gh-pages` 分支或提交构建产物。

### 多语言 SEO

构建生成五语言编辑器入口、无需 JavaScript 的介绍页，以及包含十个网址的 [sitemap.xml](https://ourtaiko.github.io/DonKanvas/sitemap.xml)。各语言提供本地化标题、分享信息、canonical 与 hreflang，介绍页突出手机、平板、桌面和便捷操作。

部署后由站点所有者在 **Google Search Console** 验证网址前缀资源并提交站点地图，在 **Bing Webmaster Tools** 同样提交；可用网址检查请求收录。收录和排名由搜索引擎决定，不由应用保证。

迁移域名时同步修改 [src/locales.js](./src/locales.js) 与 [index.html](./index.html) 的规范网址。搜索引擎只读取域名根路径 `/robots.txt`，项目子目录无需创建该文件。

## 开发与验证

Vue 3 + Vite；源码和共置单元测试位于 [src/](./src/)，部署与 PWA 集成测试位于 [tests/](./tests/)。

- [useStudio.js](./src/useStudio.js)：编辑状态、保存、草稿与 Web Audio；[chart.js](./src/chart.js) 等模块负责谱面逻辑。
- [App.vue](./src/App.vue)：应用外壳；[TimelineEditor.vue](./src/TimelineEditor.vue) 等组件负责编辑界面。
- [locales.js](./src/locales.js)：翻译与共享页面元数据；[i18n.js](./src/i18n.js) 负责语言运行时，[seo-pages.js](./src/seo-pages.js) 生成介绍页。
- [pwa.js](./src/pwa.js)：更新状态与 Service Worker 操作；[vite.config.js](./vite.config.js) 配置构建与安装清单。

```sh
npm test
npm run build
```

真实 Shift-JIS 样例测试需要上一级目录的 `夜想陽炎 - short ver.tja`。其余测试使用内置样例；PWA 测试自动构建并清理临时产物。部署约束测试 `node --test tests/deployment.test.js` 无需依赖或联网。
